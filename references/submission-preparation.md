# Submission preparation

Use this guide when the user requests submission or publication-stage checks. Follow the target venue's current official author instructions and the project's established build procedure.

## Template, anonymity, and stage

Identify the venue, year, track, and submission stage. Obtain official requirements for the document class, options, page counting, supplementary material, anonymity, artifact policies, and disclosure when relevant. Record the version of the instructions used.

A class's `review` option may add review features, but does not necessarily enforce anonymity. Camera-ready settings may require different options and author, copyright, or conference metadata. Inspect the current source rather than replacing all class options from an old example.

## Figures and layout

Inspect the compiled output at the final column width. Check overflow, readable labels and legends, placement, captions, and page counting under the venue's convention. Choose figure widths according to content; no universal fraction of column width applies.

Use the project's existing figure source policy. Editable vectors, raster illustrations, and mixed media are options selected by the user's needs and publication requirements.

## Names, macros, and references

A shared system-name macro can keep title and body consistent. Typography such as small caps is a manuscript choice. If using `xspace`, inspect spacing around punctuation and existing macro calls.

Check cross-references, citation keys, bibliography output, author metadata, and anonymous links as applicable. Verify references against original records and the claims they support. A resolvable identifier alone does not establish claim support.

## Build and final checks

Run the established build after relevant edits. Inspect titles, headers, footers, page numbers, review marks, wide figures, and the actual page count. Keep generated files in the project's designated output directory.

Deliver the requested files and report concrete completed checks. Uploading or submitting a manuscript requires the user's authorization; a formatting request alone does not authorize publication.
